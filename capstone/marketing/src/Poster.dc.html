Baton (AI Delivery Sync & Feed)
CONCEPT · 2026

FOR GITHUB + MICROSOFT TEAMS

Work isn't lost while people work. It's lost at the handoff.

Baton (AI Delivery Sync & Feed) watches the handoffs between Microsoft Teams, your GitHub board and your AI coding agents, so nothing falls between them.

01

Listen

GitHub events, agent sessions, and the Teams messages and meetings you share.

02

Match

Finds the board item a message is about, or suggests a new one. Every card shows why.

03

You decide

Approve, edit or ignore. Plain code applies it with the only write token.

Needs you

Release 2.4 is waiting for your approval to go to prod.

Suggestion

Lina's message is about #412, closed 3 days ago. Reopen it?

News

Claude opened PR #988 for the webhook retry. Tests pass.

AI suggests, you approve

Nothing is written to GitHub without your click.

Reads only what you share

Forwarded messages and meetings you run. Data stays in-region.

Facts come from GitHub

Status, owners and dates are read, never made up. Every post links back.

Quiet by default

Five pings a day at most. Everything else waits in your feed.

Built for the whole team

Starts with the programme lead. Grows into a personalized feed for every teammate: their PRs, reviews, mentions and agents.
